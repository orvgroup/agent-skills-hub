# Contributing to ORVGROUP Agent Skills Hub

Thank you for your interest in contributing!

We welcome developers, AI enthusiasts, and open-source contributors from around the world.

## How to Contribute

You can contribute in several ways:

- Add new AI agent skills.
- Improve existing skills.
- Fix errors or unclear instructions.
- Improve documentation.
- Report bugs and suggest features.

## Adding a New Skill

Each skill should have its own directory under `skills/`.

Example:

```text
skills/
  your-skill-name/
    SKILL.md
```

Every `SKILL.md` must include:

1. Valid YAML frontmatter.
2. A clear skill name.
3. A concise description.
4. Practical, step-by-step instructions.
5. Relevant examples where useful.

## Contribution Guidelines

- Keep instructions clear and practical.
- Use descriptive file and directory names.
- Avoid duplicate skills.
- Do not include passwords, API keys, or private information.
- Make sure examples are accurate and reproducible.
- Use Markdown formatting consistently.

## Submitting Your Contribution

1. Fork this repository.
2. Create a new branch for your changes.
3. Add or update the relevant files.
4. Review your changes.
5. Submit a Pull Request with a clear description.

## Pull Request Guidelines

Please explain:

- What you changed.
- Why the change is useful.
- How the contribution can be tested or verified.

## Questions and Suggestions

If you find a problem or have an idea, open an issue in this repository.

Thank you for helping make this project useful to the open-source community!
