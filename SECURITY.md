# Security Policy

## Supported Versions

The latest version of ORVGROUP Agent Skills Hub is currently supported for security updates.

Older versions may not receive security fixes.

## Reporting a Vulnerability

If you discover a potential security vulnerability in this repository, please report it responsibly.

**Please do not disclose security vulnerabilities through public GitHub Issues, Discussions, or Pull Requests.**

If private vulnerability reporting is enabled for this repository:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Provide details about the issue, its potential impact, and steps to reproduce it.

If private vulnerability reporting is unavailable, contact the repository maintainer privately through GitHub before sharing technical details publicly.

## What to Include

Please include as much of the following information as possible:

- Description of the vulnerability.
- Affected file or component.
- Steps to reproduce the issue.
- Potential security impact.
- Proof of concept, if available.
- Suggested mitigation, if known.

## Response Process

The maintainers will:

1. Review the report.
2. Assess the severity and impact.
3. Investigate and work on a fix.
4. Coordinate disclosure with the reporter.
5. Publish relevant security updates when appropriate.

## Responsible Disclosure

We ask security researchers to allow reasonable time for investigation and remediation before publicly disclosing vulnerabilities.

Thank you for helping keep ORVGROUP Agent Skills Hub secure.
