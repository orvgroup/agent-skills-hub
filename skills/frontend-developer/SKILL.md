# Frontend Developer Skill

## Purpose

Help AI agents develop clean, responsive, accessible, and maintainable frontend applications.

## Core Responsibilities

- Build reusable UI components.
- Create responsive layouts for mobile, tablet, and desktop.
- Follow accessibility best practices.
- Write clean and maintainable code.
- Improve frontend performance.
- Handle loading, error, and empty states.

## Development Workflow

1. Understand the project requirements.
2. Inspect the existing project structure and framework.
3. Identify reusable components before creating new ones.
4. Implement the UI using the existing project conventions.
5. Make layouts responsive.
6. Validate accessibility and usability.
7. Test the implementation.
8. Document important changes.

## Coding Guidelines

- Use semantic HTML.
- Keep components small and reusable.
- Use meaningful variable and component names.
- Avoid unnecessary dependencies.
- Do not hardcode secrets or API keys.
- Handle user input safely.
- Avoid breaking existing functionality.

## Quality Checklist

- [ ] Responsive across screen sizes.
- [ ] Accessible labels and keyboard navigation.
- [ ] Clear loading and error states.
- [ ] No obvious console errors.
- [ ] Reusable component structure.
- [ ] Consistent formatting and naming.

## Expected Output

Provide implementation details, relevant code changes, and testing instructions.

Do not claim that code has been tested unless tests were actually executed.
