# Code of Conduct

## Our Commitment

ORVGROUP Agent Skills Hub is an open-source project. We are committed to providing a welcoming, respectful, and harassment-free environment for everyone.

We welcome contributors regardless of experience level, background, identity, or location.

## Expected Behavior

All community members are expected to:

- Be respectful, professional, and constructive.
- Welcome different opinions and perspectives.
- Give and accept feedback gracefully.
- Focus on what is best for the community.
- Help create a positive environment for everyone.
- Respect other people's time and contributions.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment, discrimination, or personal attacks.
- Hate speech or abusive language.
- Trolling, insults, or deliberately disruptive behavior.
- Publishing private information without permission.
- Spam or intentionally misleading contributions.
- Any conduct that creates an unsafe or hostile environment.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues
- Pull Requests
- Discussions
- Project-related communication and community spaces

## Reporting

If you experience or witness unacceptable behavior, report it privately to the repository maintainers through GitHub.

Please do not disclose sensitive personal information in public reports.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

Depending on the severity of the behavior, maintainers may:

1. Issue a warning.
2. Remove inappropriate comments or contributions.
3. Temporarily restrict participation.
4. Permanently ban individuals from the project.

Maintainers will handle reports fairly and confidentially.
